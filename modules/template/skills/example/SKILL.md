# Example

Write the instructions the way you would explain the job to a careful person
who has never done it before. Plain sentences beat clever structure.

## What to include

- Where things get written, exactly. A folder and a filename, not "somewhere
  sensible".
- What to do first, and what to check before writing anything.
- What NOT to do. Rules against inventing dates, numbers, or facts belong here,
  because that is where they actually hold.

## What to leave out

- Personality. The user already chose a voice for their assistant, and a module
  that overrides it will be uninstalled by lunchtime.
- Anything you would not want running against your own notes.

Delete this file and write yours. One skill that does one job well is worth
more than five that half-work.
