# Weekly review

Reads the week's daily notes and writes the review you would write if you
could remember Monday on a Sunday evening.

Say any of these and it runs:

- "how was my week"
- "weekly review"
- "wrap up the week"
- "what should next week look like"

It writes to `50-daily/reviews/YYYY-Www.md` in your brain folder, and it only
uses what your daily notes actually say. Days you did not write are reported as
days you did not write, never filled in.

**What it adds:** one skill. No scripts, no hooks, nothing that runs on its
own.
